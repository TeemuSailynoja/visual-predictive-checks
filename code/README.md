# Supplementary materials and code implementations
[![DOI](https://zenodo.org/badge/939910801.svg)](https://doi.org/10.5281/zenodo.15189798)

This directory holds up to date versions of the extended case-studies and code linked to the article [Recommendations for visual predictive checks in Bayesian workflow](https://www.journalovi.org/2025-sailynoja-visual-predictive-checks/) 

- [**quarto**](https://github.com/TeemuSailynoja/visual-predictive-checks/tree/main/code/quarto): More extended case-studies on the examples shown in the article.

- [**R**](https://github.com/TeemuSailynoja/visual-predictive-checks/tree/main/code/R): Implementations of the visualization functions and PIT computations used in the article.

- [**stan**](https://github.com/TeemuSailynoja/visual-predictive-checks/tree/main/code/stan): Source code for the probabilistic models used in some of the case-studies.
